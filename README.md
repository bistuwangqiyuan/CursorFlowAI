# CursorFlow AI — 商业计划书（自用决策与执行手册）

一份关于「要不要做一个 AI 编程周边的单人无人化 SaaS」的决策文件。
产出是 `outputs/商业计划书.pdf`（45 页）。

**它的结论是一个有条件的否定**：在把时间按机会成本计价的口径下，完整投入
3,000 小时的期望值为负；但前三道门只需 96 小时、$524，就能把两个决定成败的
未知数（拿不拿得到流量、有没有人肯付钱）变成事实。所以建议只批准这 96 小时。

这份文件的读者是作者本人，因此不含任何对外融资条款，也不为任何结论辩护。
第十二章「红队自检」列出了它自己最可能错在哪里。

## 复现

```bash
pip install -r requirements.txt
playwright install chromium
python build.py
```

`build.py` 串起五步，任一步失败即整体失败并保留退出码（可直接放进 CI）：

| 步骤 | 脚本 | 守什么 |
| --- | --- | --- |
| 1 | `model/run_all.py` | 跑全部模型，写 `outputs/results.json` 与 8 张 SVG；含跨模型一致性对账 |
| 2 | `bp/build_html.py` | 从 `results.json` 渲染正文；关键数字取不到即抛异常 |
| 3 | `tools/audit_numbers.py` | 模型数字不被手打偷偷替换（见 PDF 附录 C.3） |
| 4 | `tools/font_coverage.py` | 所有字符都由随仓库携带的字体覆盖，不回退到系统字体 |
| 5 | `bp/build_pdf.py` | 导出 PDF 并校验字体嵌入、页数、分页断裂 |

随机种子固定为 `20260727`。`python tools/verify_reproducible.py` 会重跑一遍并比对，
用来证明这句话是真的而不是一句承诺：**8 张 SVG 逐字节一致，9 份 JSON 在剔除
构建元数据（时间戳、git rev、耗时）后一致**。构建元数据按设计每次不同。

（这条检查是红队自检的产物：第一次真去核就发现不成立——SVG 里有 `<dc:date>`
和随机生成的 clipPath id。数字一直是对的，但「文件可逐位复核」当时是假的。）

## 目录

| 路径 | 内容 |
| --- | --- |
| `model/` | 全部计算。`assumptions.py` 是唯一的假设来源，每个常量注明出处或标记为推测 |
| `research/` | 事实底稿。`sources.md` 是全部事实陈述的单一出处，含五级证据分级 |
| `docs/` | 各专题的完整论证：Gate 0 阻断性验证、付费意愿证伪方法、获客方案、止损门 |
| `bp/` | 正文生成器与样式（`build_html.py` 不含任何手打的模型数字） |
| `tools/` | 构建期的校验与目检工具 |
| `assets/fonts/` | 随仓库携带的开源字体，见 `LICENSES.txt`。不依赖系统字体是可复现的前提 |
| `outputs/` | 产出：PDF、`results.json`、SVG 图表 |

## 两条自我约束

**数字分两类，两类各有各的保证。** 模型算出来的数字（工时、金额、概率、转化率）
一律经白名单从 `results.json` 取，取不到就构建失败——所以正文不可能与模型脱节。
外部事实数字（竞品定价、他人营收、法规日期）是手打的，但**本就不该**来自本项目的
模型，它们的效力来自出处，因此每处就近标注来源与核查日期。这个边界由
`tools/audit_numbers.py` 钉成基线守住：新增任何手打数字都会让构建失败，
必须显式复核入基线并留下 diff。

**标准写死在版本控制里。** 本文件的作者和执行者是同一个人，门是自己定的也是自己
判定的。没有第三方能阻止我在第 12 个月说服自己「再给三个月」。唯一可用的对冲是让
每一次放松标准都留下 diff。这不完美，但比什么都不做强。
